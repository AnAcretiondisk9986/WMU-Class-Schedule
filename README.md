# WMU 课表 PDF 解析器

面向温州医科大学教务系统导出的横向课表 PDF。解析器直接使用 PDF 文本层和文字坐标，不依赖 OCR。

## 近期更新

### 更新声明（2026-08-17）

本次更新聚焦课表浏览的稳定性与可读性，不改变本地课表数据结构和 PDF 导入协议：

- 宽屏侧栏固定在视口左侧，滚动课程内容时导航始终可用。
- 当前周的当天列以淡红色标注；正在上课的课程卡片以 `#DEBA85` 高亮。
- 竖屏页面的顶栏固定在顶部，搜索与导入入口随时可用。
- 校区作息改为按节次显式配置，不再用固定 45 分钟公式推算：茶山与学院路第 1 节从 `08:00` 开始，滨海第 1 节从 `08:30` 开始；滨海第 7 节为 `13:05–13:20`，三校区第 8 节统一为 `13:30–14:10`、第 14 节统一为 `18:20–19:00`。网页、小程序和跨校区冲突检测使用同一规则。
- 课程地点文字不再被省略或隐藏；定位图标独占居中行，识别出的 4–6 位字母数字教室号单独居中成行并与后续说明分隔，窄屏竖屏下按 4/5/6 位映射字号以避免出框，其他地点在等宽文本区域内自然换行。卡片内部采用正常文档流和独立滚动，禁止文本与相邻课程重叠。
- 茶山、滨海地点仅在原始文本开头为 4–6 位字母数字编码时后处理：移除“智慧教室”“计算机机房”等附注；学院路及未识别格式保留原样。
- 新增三页无冲突高强度合成测试 PDF 与可重复生成脚本，覆盖 28 条事件、六种活动类型、极端文本、地点格式和时间边界，可先用于验证课表能否正常导入显示。
- 同一时间发生多门课程时改为稳定分层显示，优先级为“讲课 > 线上 > 无地点 > 学习通等线上平台”；鼠标悬停或键盘聚焦的卡片会临时置顶，便于查看被遮挡内容。
- “讲课”“实验”等课程类型标签统一固定在卡片底部居中，课程正文使用独立滚动区；紧凑与极小卡片也不会隐藏标签或让标签覆盖正文。

### 网页端移动体验

- 移动端锁定页面缩放，避免双指缩放破坏七列课表布局。
- 在周视图中左右拖动可切换上一周或下一周；相邻两周会提前渲染，拖动时对应周内容实时跟手出现，快速轻扫可按方向切换，首末可用周次会回弹。
- 课程详情支持向右跟手滑动关闭，抽屉与遮罩会同步响应位移和释放速度。
- 左上角校徽现在是导航入口：点击后呼出完整侧栏，底部导航同时向下退出视口；可点击遮罩、关闭按钮或按 `Esc` 返回。
- 周视图表头同时显示「周一至周日」和对应的 `MM/DD` 日期。
- 窄屏课程卡片会按实际高度自动收紧：优先保留课程名与上课时间，逐级隐藏次要信息并限制文本行数，避免文字重叠。
- 实际时长恰好为 40 分钟的课程卡片仅显示课程名称和地点文字，不渲染定位图标、时间、教师校区信息或课程性质。
- 为 `prefers-reduced-motion` 提供更轻量的过渡效果。


## 为什么必须读取坐标

课表 PDF 的文本内容按页面绘制顺序保存，直接拼接文本会丢失“星期几”信息，也会在分页处把不同课程混在一起。解析器先按横坐标恢复星期一至星期日七列，再在每列内解析课程。

该格式中：

- `(2-5节)` 是上课节次。
- `1-2周,4-12周(双),13-17周(单)` 是周次和单双周。
- `◆`、`◇`、`▲`、`●`、`#`、`□` 分别表示讲课、实验、在线、讨论、实践和自主学习。

## 使用

```js
import * as pdfjsLib from "pdfjs-dist/legacy/build/pdf.mjs";
import { parseTimetablePdf } from "./src/timetable.js";

const result = await parseTimetablePdf(file, pdfjsLib);
console.log(result.courses);
console.log(result.events);
```

`file` 可以是浏览器 `File`、`ArrayBuffer` 或 `Uint8Array`。结果包含学期、学生信息、合并后的课程列表、逐条上课事件和解析警告。

## 导入 PDF

可点击「导入 PDF」弹窗中的「前往教务系统查询课表」打开个人课表查询页。在教务系统正常导出课表 PDF 后，回到网页选择该文件，或将文件拖入弹窗。该按钮只负责打开链接；页面不读取教务系统内容。PDF 只在当前浏览器中解析，不会上传到项目服务器。
